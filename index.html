Gemini로 첫 코드 받기
제작 시작

      
Gemini는 내 설명을 코드로 바꿔 주는 동료예요. 한 채팅방에서 계속 대화해야 Gemini가 내 게임을 기억해요.

      
    
        
  1. 크롬에서 gemini.google.com에 접속해 로그인해요.
    2. 
        
  2. 화면 왼쪽 위의 새 채팅을 눌러 빈 대화방을 열어요.
    3. 
        
  3. 1단계에서 복사한 요청문을 입력창에 붙여 넣고(Ctrl+V) 전송해요.
    4. 
        
  4. 답변 속 회색 코드 상자의 오른쪽 위 복사 아이콘을 눌러 코드 전체를 복사해요.
    5. 
        
  5. 코드 아래 설명도 한 번 읽어 보세요. 어떤 기능이 들어갔는지 알려 줘요.
    6. 
      

      
코드가 중간에 끊겼다면?같은 채팅방에 이렇게 보내요. "코드가 중간에 끊겼어. index.html 하나에 들어가는 전체 코드를 처음부터 다시 줘."

      
코드 상자가 여러 개로 나뉘어 나오면(HTML, CSS, JS 따로) "세 개를 하나의 HTML 파일로 합쳐서 전체 코드를 줘"라고 다시 요청하세요.

      

        
        
      

    


    
    

      
3
VS Code에서 실행하기

      
복사한 코드를 파일로 저장하고, 브라우저에서 내 방탈출을 처음 열어 봐요.

      
    
        
  1. 바탕화면에 새 폴더를 만들고 이름을 escape-room으로 정해요.
    2. 
        
  2. VS Code를 열고 파일 → 폴더 열기에서 escape-room 폴더를 선택해요. "작성자를 신뢰합니까?" 창이 뜨면 예를 눌러요.
    3. 
        
  3. 왼쪽 탐색기에서 새 파일 아이콘을 누르고 이름을 index.html로 입력해요. 이 이름이어야 배포했을 때 첫 화면으로 열려요.
    4. 
        
  4. 편집창을 클릭하고 Ctrl+V로 붙여 넣은 뒤 Ctrl+S로 저장해요.
    5. 
        
  5. 확장 탭(Ctrl+Shift+X)에서 Live Server를 검색해 설치해요. 이미 있으면 건너뛰어요.
    6. 
        
  6. 편집창에서 마우스 오른쪽 버튼 → Open with Live Server를 누르면 브라우저에 게임이 열려요. 이제 저장할 때마다 화면이 자동으로 새로고침돼요.
    7. 
      

      
Live Server가 안 된다면?escape-room 폴더에서 index.html을 더블클릭해도 열려요. 이때는 저장 후 브라우저에서 F5를 눌러 새로고침해요.

Gemini에게 구체적으로 말하기

      

        
이렇게 말하면 Gemini도 헷갈려요이상해. 고쳐줘.

        
이렇게 말해요사물함을 클릭해도 아무 일도 안 일어나. 클릭하면 단서 창이 뜨게 고치고 전체 코드를 다시 줘.

      

      

        
막연한 요청더 멋있게 해줘.

        
분명한 요청배경을 짙은 남색으로 바꾸고, 물건 위에 마우스를 올리면 노란빛이 나게 해줘.

      


      
화면이 하얗거나 버튼이 안 눌릴 때

      
    
        
  1. 게임이 열린 브라우저에서 F12를 누르고 Console 탭을 열어요.
    2. 
        
  2. 빨간 글씨로 된 오류 메시지를 드래그해서 복사해요.
    3. 
        
  3. Gemini에 "이런 오류가 나와: (붙여넣기). 고친 전체 코드를 줘."라고 보내요.
    4. 
        
  4. VS Code에서 Ctrl+A로 기존 코드를 모두 선택하고, 새 코드로 붙여 넣은 뒤 저장해요.
    5. 
      

      
"전체 코드를 다시 줘"를 붙이는 이유일부만 받으면 어디에 넣어야 할지 헷갈려서 오류가 나기 쉬워요. 통째로 바꾸는 것이 가장 안전해요.


      
간단한 글자는 직접 고쳐 보기

      
VS Code에서 Ctrl+F를 누르고 탈출 성공처럼 화면에 보이는 문구를 검색해 보세요. 그 글자를 직접 바꾸고 저장하면 바로 반영돼요. 코드가 어떻게 생겼는지 알아 가는 첫걸음이에요.

GitHub에 배포하기

      
2차시에 퀴즈를 올렸던 방법과 같아요. 배포하면 친구가 링크만으로 내 방에 들어올 수 있어요.

      
    
        
  1. github.com에 로그인하고, 오른쪽 위 + → New repository를 눌러요.
    2. 
        
  2. Repository name에 escape-room을 입력하고 Public을 선택한 뒤 Create repository를 눌러요.
    3. 
        
  3. 다음 화면의 uploading an existing file 링크를 누르고, index.html을 끌어다 놓은 뒤 Commit changes를 눌러요.
    4. 
        
  4. Settings → 왼쪽 메뉴 Pages로 가서 Branch를 main, 폴더를 / (root)로 고르고 Save를 눌러요.
    5. 
        
  5. 1~2분 기다린 뒤 새로고침하면 위쪽에 주소가 나타나요. 보통 https://내아이디.github.io/escape-room/ 모양이에요.
    6. 
      

      
배포한 뒤에 또 고쳤다면?저장소 화면에서 Add file → Upload files로 수정한 index.html을 다시 올리고 Commit하면 덮어써져요. 반영까지 1~2분 걸려요.
